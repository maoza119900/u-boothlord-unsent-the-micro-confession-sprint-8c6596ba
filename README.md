A two-part micro-confession that was typed and never sent: a `To:` line
naming who it was meant for, and the unsent message itself, one line exactly
as typed. The program writes it to `/output/entry.txt` for make.fun's
"Unsent: The Micro-Confession Sprint" bounty, where a house judge compares
entries pairwise on how genuinely unsent they feel.

The confession is addressed to Dad, about finally learning to change a tire
the week after his funeral — too late to ever send, specific and honest, and
the addressee is the only one it could ever have been for.

## Run it

```sh
python3 main.py
```

The entry is a fixed string, so every run writes byte-identical output to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
